# 🐙 Consumindo API do GitHub

Aplicação web que consome a **GitHub REST API** e exibe dinamicamente os repositórios públicos de um usuário, com nome, URL e data de criação formatada em pt-BR.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)

---

## ✨ Funcionalidades

- Busca automática dos repositórios de um usuário do GitHub
- Exibição do nome, URL e data de criação de cada repositório
- Interface responsiva com `fetch` + `async/await`

## 🚀 Como executar

Basta abrir o arquivo `index.html` no navegador, ou servir a pasta localmente:

```bash
# com Python
python -m http.server 8080
```

Acesse [http://localhost:8080](http://localhost:8080).
